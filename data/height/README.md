# data/height

Höhendaten (digitales Geländemodell, 1 m Auflösung). **Erforderlich** – ohne Daten hier bricht der
Export sofort ab ("Keine DGM1-Kacheln gefunden").

- LGL Baden-Württemberg: ZIP-Dateien mit ASCII-XYZ-Punktwolke, Name `dgm1_32_<x>_<y>_2_bw.zip`.
- Andere Region: ein oder mehrere georeferenzierte GeoTIFF-DEMs, beliebiger Dateiname, lose oder im ZIP.

Die Fläche des Exports ergibt sich aus den hier liegenden Kacheln.
